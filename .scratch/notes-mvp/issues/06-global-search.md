# 06 — Global live Search across Notes and Folders

**What to build:** A search entry point that filters live as the user types, matching both a Note's derived title and its body content, across every Folder and Unfiled Notes at once. Each result shows which Folder it belongs to (or that it's Unfiled) for context.

**Blocked by:** 02, 05

**Status:** ready-for-agent

- [ ] Search results update live as the user types, with no separate "search" action to press
- [ ] A query matches against both a Note's derived title and its body content
- [ ] Results span every Folder and Unfiled Notes — search is never scoped to only the currently open Folder
- [ ] Each result shows which Folder it's in (or "Unfiled" if it has none)
- [ ] Tapping a result opens that Note directly
